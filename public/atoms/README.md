# Atom portraits

Drop a real portrait PNG here, one per Atom, named exactly:

- `Mabel.png`, `Hazel.png`, `Willa.png`, `Ruby.png`, `June.png`,
  `Sadie.png`, `Bea.png`, `Flora.png`, `Pearl.png`, `Iris.png`,
  `Cleo.png`, `Nora.png`

Square, at least 256x256. The app uses the PNG when it exists and falls
back to a generated placeholder tile (initial + triangle) when it does not.

All twelve are in place (Nov 19, 2026): 1950s pulp-poster portraits in
the same family as the Photon portraits — painted with real depth and
texture on aged cream paper, teal/red/butter-yellow palette, a genuine
range of races and backgrounds, each keeping its role's costume, emblem,
and prop — Mabel (Black woman, letters and red pencil), Hazel (East
Asian older woman, pocket diary), Willa (Latina woman, morning paper
and mug), Ruby (South Asian woman, telephone handset), June (young
person, lantern), Sadie (person with an hourglass), Bea (Latina older
woman, journal and lamp), Flora (Black woman, apron and house key),
Pearl (South Asian man, ledger book), Iris (Middle Eastern woman, card
catalog box), Cleo (Latino man, clipboard), Nora (older woman, compass).
If a portrait is ever replaced, drop the new file here with the same
name and redeploy; the service-worker cache version must be bumped too,
or existing installs will keep serving the cached portrait.
