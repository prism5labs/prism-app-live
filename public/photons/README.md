# Photon portraits

Drop a real portrait PNG here, one per Photon, named exactly:

- `Prism.png`, `Juniper.png`, `Encore.png`, `Zero.png`, `Proof.png`,
  `Barnstormer.png`, `Blueprint.png`, `Calendra.png`, `Shopbell.png`,
  `Keystone.png`, `Vesper.png`, `Goldstar.png`

Square, at least 256x256. The app uses the PNG when it exists and falls
back to a generated placeholder tile (initial + triangle) when it does not.

All twelve are in place (Nov 17, 2026): eleven are new 1950s
pulp-poster portraits showing a genuine range of races and
backgrounds, each keeping its role's costume, emblem, and prop —
Prism (Prism 5 herself — the approved Jeeves avatar face: Florence
Pugh base, fair freckled skin, spiky blue-black faux hawk, vibrant blue
eyes, red lipstick; same still, crystalline bodysuit, light beam), Juniper
(Latina woman, juniper emblem, wooden box), Encore (Black woman,
mandolin), Zero (East Asian person, gold "O", letters), Proof
(South Asian woman, magnifying glass, checkmark), Blueprint (Black
woman, braided ponytail, blueprints and tool belt), Calendra (East
Asian older woman, calendar), Shopbell (Latino man, bell and apron,
parcel), Keystone (Middle Eastern older person, key emblem), Vesper
(Latina woman, crescent moon and stars), Goldstar (South Asian man,
gold star and prize ribbon). Barnstormer is unchanged — the aviator
Neil already loves, kept as the standard. The new portraits are
1600x1600 PNGs (the originals were 640x640). If a portrait is ever
replaced, drop the new file here with the same name and redeploy;
the service-worker cache version must be bumped too, or existing
installs will keep serving the cached portrait.
